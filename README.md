# Telegram TXT File Batch Downloader Bot

यह बॉट एक `.txt` फ़ाइल इनपुट के रूप में लेता है जिसमें वीडियो के लिंक्स होते हैं, और एक-एक करके सभी वीडियो को डाउनलोड करके टेलीग्राम पर भेजता है।

## आवश्यक पर्यावरण चर (Environment Variables)

होस्टिंग प्लेटफ़ॉर्म (Koyeb / Render / VPS) पर निम्नलिखित वैरिएबल्स सेट करें:
- `API_ID`: आपकी Telegram App ID
- `API_HASH`: आपकी Telegram App Hash
- `BOT_TOKEN`: @BotFather से प्राप्त टोकन
